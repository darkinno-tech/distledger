# Code of Conduct

## The short version

Be decent to people. Argue about the code, not the person. Assume the other person knows
something you do not, because in a project like this they usually do.

## Scope

This applies to issues, pull requests, discussions, commit messages, code comments and any
other project space, and to anyone participating in them.

## Expected

- **Criticise the change, not the contributor.** "This drops the invariant on the reversed
  bucket" is useful. "Did you even read the ADR" is not.
- **Say what you measured.** This project resolves disagreements with evidence rather than
  confidence, and that works better when everyone does it.
- **Assume good faith on scope.** A proposal that belongs outside the kernel is not a
  stupid proposal; the scope list is long and the dividing line is genuinely subtle.
- **Accept that "no" is a complete answer.** This is a small project with a deliberately
  narrow scope, and most feature requests will be declined with a reason.
- **Be patient about time.** There is no guaranteed response time.

## Not acceptable

- Harassment, insults, or personal attacks of any kind
- Discriminatory language or behaviour, including on the basis of gender, gender identity,
  sexual orientation, disability, ethnicity, nationality, age, religion, or appearance
- Sexual attention or advances in project spaces
- Publishing someone's private information without permission
- Deliberately derailing or derailing-by-volume: restating a settled position without new
  information, or opening the same argument across several threads
- Using the issue tracker to pursue a grievance about another project or person

## Reporting

Report anything you experience or witness to the maintainers privately:

**DarkInno@mail.im10furry.cn** — the organization's published contact address. Or, if you
would rather not use email, open a public issue saying only that you need a private channel,
with no details.

Reports are handled confidentially. The maintainers will not share identifying information
about a reporter without consent, and will recuse themselves from handling a report that
involves them.

## Consequences

Depending on severity and pattern, from a private word, through a public correction or a
request to disengage from a thread, to a temporary or permanent ban from project spaces.
Maintainers who do not follow this code face the same consequences as anyone else.
